# stroke-prediction-medium-tree-svm
Machine learning-based stroke prediction using Medium Tree and Coarse Gaussian SVM classifiers.
# Analysis and Prediction of Stroke Using Medium Tree and Coarse Gaussian SVM Classifiers

## Overview
This project focuses on predicting stroke risk using machine learning techniques. Medium Tree and Coarse Gaussian SVM classifiers were developed and evaluated using healthcare data to support early stroke detection.

## Technologies Used
- MATLAB
- Machine Learning
- Classification Learner
- SMOTE

Published in IEEE Conference Proceedings.
